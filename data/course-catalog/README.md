# 全校課程資料庫規格

## 目標
以電機工程學系學士班學生為判定基準，建立可供「方案找課程」及「課程找方案」雙向查詢的中興大學全校課程資料庫。

## 官方資料來源
- 中興大學課程查詢系統（歷年／全校查詢）：https://onepiece.nchu.edu.tw/cofsys/plsql/crseqry_home
- 系、所、學位學程查詢：https://onepiece.nchu.edu.tw/cofsys/plsql/crseqry_home2
- 當學期查詢：https://onepiece.nchu.edu.tw/cofsys/plsql/crseqry_home_now
- 教務處課程查詢說明：https://oaa.nchu.edu.tw/zh-tw/faq/faq-list.5

官方系統提供學年期、學制、系所、年級、科目名稱、教師、上課時間、授課語言及 EMI 等查詢條件；課程查詢結果可連至課程大綱。資料匯入時必須保留查詢學年期及官方課程識別資料。

## 資料範圍
- 預設先匯入 115 學年度第 1 學期（1151）全校學士班開課課程。
- 後續按學期保存歷史快照，不覆蓋舊學期資料。
- 範圍包含各系所課程、通識課程、綜合課程（含微課程）、學程課程及全校可選修課程。
- 研究所課程可保留在資料源，但不得自動當成學士班可修或可採計課程；需另記錄選課限制及核准條件。

## 每門課的欄位
- courseId / courseNo：課程 ID、選課號碼
- academicTerm：學年期（例如 1151）
- courseName：課程名稱
- department：開課系所／單位
- programLevel：學制
- grade：開課年級
- credits：學分
- requiredType：必修／選修／通識／學程／其他（來源未提供時留空，不推測）
- classGroup：班別
- instructor：授課教師
- language / emi：授課語言及 EMI
- schedule：上課時間
- capacity / enrolled：名額與選課人數（來源有提供才保存）
- syllabusUrl：課程大綱網址（有可靠連結才保存）
- sourceUrl / fetchedAt / sourceStatus：來源、抓取時間、核實狀態

## 重要判定原則
1. 「課程有開設」不等於「電機系學生一定能選到」；需另存選課對象、年級、先修、名額及加簽限制。
2. 「可以選修」不等於「可以計入電機系畢業學分」；課程採計必須連到電機系適用入學年度的正式規則。
3. 課程名稱相似不代表等同；系必修替代、抵免、跨系採計需有官方依據或核准紀錄。
4. 同一課號若有系所班與通識深耕班，必須分開保存；不可重複採計。
5. 同一課程在不同學期的開課資訊是不同快照，不能只用課名合併。
6. 尚未取得完整課程資料時，介面必須明示資料涵蓋學期及缺漏狀態，不得用少量樣本假裝全校完整清單。

## 雙向互動
### 方案 → 課程
選擇電機必修、電機專業選修、專業學程、通識、跨系選修、輔系、雙主修、跨域專長或學分學程後，依已核實規則標亮可用課程；待確認與不適用課程分色呈現。

### 課程 → 方案
選擇課程後，顯示可對應的畢業類別與方案，逐項顯示依據、學分上限、重複採計限制及是否需要申請核准。

## 資料狀態
- verified：已由官方課程查詢系統核對
- pending：來源可辨識但欄位或適用限制尚待核對
- unavailable：目前無法取得可靠資料
- mapping_verified：課程對應／採計規則另有正式依據
- mapping_pending：尚未取得足夠依據，不得自動算入

全校課程清單與電機系畢業採計規則是兩個不同資料層，必須分開維護。
