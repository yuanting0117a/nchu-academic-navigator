# 正式規則資料

正式資料依「學制／系所／入學年度／適用效期」分層管理。每條規則需含適用範圍、判斷邏輯、官方來源、條文／頁碼、核實日期與核實狀態。目前尚未放入完整正式畢業條件，避免示範資料被誤認為校方規定。

## 跨系畢業路徑資料模型

### 1. 目前學籍（origin）
記錄目前正式學籍，例如電機工程學系、學士班、入學年度。這是起始狀態，不代表最終一定要從原系畢業。

### 2. 候選畢業系所（target）
全校各學系／學位學程都可成為候選目標。每個目標必須載入該系適用入學年度的完整畢業條件，逐條比對同一份個人修課紀錄。

### 3. 課程採計（course_credit_mapping）
每門課需分別判斷可否列入目標系的：
- 系必修
- 系選修
- 院必修／院選修
- 校訂必修
- 通識
- 畢業總學分
- 其他指定類別

不得因課名相似就自動認定等同；抵免、替代及重複採計規則必須有官方依據。無法確認者標記「待人工確認」。

### 4. 轉系流程（transfer）
轉系是獨立流程，不可與課程完成度合併：
- 是否符合申請資格
- 申請年級／時間限制
- 目標系當年度是否開放及其申請條件
- 應備文件
- 審查／名額／考試等要求
- 正式核准結果
- 轉入後適用的畢業條件與應補修科目

未核准前，目標系只顯示「模擬修課路徑」，不能標示為正式可由該系畢業。

### 5. 最終判定狀態
每個候選目標分別顯示：
- 課程條件已符合
- 尚缺課程／學分
- 待修課程中
- 待人工確認
- 轉系資格不符／尚未確認
- 申請中
- 已核准轉入
- 轉入後畢業條件已符合

「課程條件已符合」不等於「已取得該系學籍」或「已取得畢業資格」。

## 官方資料入口

- 中興大學教務處註冊組：畢業條件明細表及審查流程
- 中興大學教務處註冊組：轉系作業及各系轉系申請須知
- 中興大學教務處法規章則：轉系辦法、抵免學分辦法、畢業資格審核作業要點

正式資料匯入時，請保存原始官方文件與可追溯的條文／頁碼；網站資料更新後需重新核實。
