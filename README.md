# 中興大學學業導航系統

Repository: `nchu-academic-navigator`  
Version: `v1.3.0`

中興大學全校系所學業導航工具。以目前電機工程學系學籍作為初始起點，並可比較其他系所作為「可能的最終畢業系所」的修課與轉系路徑。

## 技術架構
- GitHub Pages 靜態網站，無需付費後端
- localStorage 儲存個人修課資料
- JSON 匯出備份
- 規則引擎與正式規則資料分離
- 未核實條件一律標示「待人工確認」

## 部署
Repository → Settings → Pages → Deploy from a branch → Branch: `main` → Folder: `/(root)` → Save。

## 跨系畢業路徑（核心需求）
- 系所目錄涵蓋全校各學院、學系及學位學程；目前先以學士班路徑建置，其他學制依官方資料逐步擴充。
- 初始個人檔案以電機工程學系為目前學籍起點；修課紀錄是跨系比對的共同基礎。
- 每個其他系所都可作為候選目標，逐項比對其適用入學年度的必修、選修、通識、總學分及其他畢業條件。
- 同一門已修課程可同時拿去比對不同目標系所，但是否能抵免、列入系選修或重複採計，必須依目標系所正式規定判斷，不能自行假設。
- 將「課程條件達標」與「正式取得目標系所學籍」分開。轉系資格、申請期限、文件、名額／審查、核准結果及轉入後適用的畢業規定，都是獨立節點。
- 未正式核准轉系前，其他系所只能顯示為模擬路徑，不得顯示為可直接從該系畢業。
- 轉系核准後，依轉入系所及適用年級／入學年度規定重新計算應補修科目與學分；需要系所認定的項目標示「待人工確認」。
- 同時檢查各類學分上限：每學期修課上限、外系選修採計上限、通識／系選修／學程採計上限、抵免上限及畢業總學分門檻；超修例外與核准條件另列。
- 支援學分轉換與抵免：外校／交換修課、校際選課、轉系或轉學後的課程抵免、課程等同／替代、部分採認及不同學分換算。每筆轉換保留原始學分與目標採認學分，不直接覆蓋原紀錄。

## 跨域制度分類
系統分別處理跨領域學分學程／微學分學程、領域模組、跨域專長、跨域探索學分、輔系、雙主修、院學士學位、校學士學位及轉系。它們取得的成果不同：證明書、畢業證書加註、第二主修或不同學士學位不可混為一談。尤其雙主修在特定條件下可能有以加修系畢業的替代路徑，必須獨立建模。

## 通識自主學習學分
除一般課程外，納入通識微型課程、興通識online、實作專題、跨域自主學習活動、生活實踐等正式自主學習學分來源。點數／時數依類別分池計算，分別檢查門檻、上限、報告、審查、核發與成績登錄；不得將所有活動點數混成同一個集點池。

## 正式資料原則
每條規則需記錄學制、系所、入學年度、適用期間、判斷邏輯、官方來源、條文或頁碼、核實日期及狀態。

## 開發階段
1. 建立全校學院、系所與學位學程目錄
2. 以電機工程學系為目前起點，建立個人修課資料
3. 匯入各系學士班畢業條件，逐系比對候選目標系所
4. 建立轉系資格、申請、審查、核准及轉入後補修流程
5. 完成 AND／OR／至少 N 項／學分上下限／先修規則
6. 建立課程等同、學分轉換、抵免審查與跨系採計規則
7. 比較原系畢業、轉系後畢業及跨域修讀路徑

本工具僅供學業規劃參考，不取代中興大學教務處、各系所或學程的正式規定與審查結果。

- 新增資訊工程學系115學年度起入學正式畢業條件資料：128總學分、通識28、系專業必修55（21門）、系專業選修至少30；外系課程有明確排除清單，系必修原則上必須由資工系開課。詳見 [`data/departments/computer-science-bachelor-115.json`](data/departments/computer-science-bachelor-115.json)。
- 已核實資工系115學年度版本：系網目前列示115年10月22日校課程會議通過版本；先前搜尋索引出現的「尚待院校追認」文字已過時，應以目前正式頁面及附件為準。
