# 中興大學學業導航系統

Repository: `nchu-academic-navigator`  
Version: `v0.1.0`

中興大學畢業條件、修課要求、先修規則、輔系／雙主修／學分學程申請流程的互動式學業導航工具。

## 技術架構
- GitHub Pages 靜態網站，無需付費後端
- localStorage 儲存個人修課資料
- JSON 匯出備份
- 規則引擎與正式規則資料分離
- 未核實條件一律標示「待人工確認」

## 部署
Repository → Settings → Pages → Deploy from a branch → Branch: `main` → Folder: `/(root)` → Save。

## 正式資料原則
每條規則需記錄學制、系所、入學年度、適用期間、判斷邏輯、官方來源、條文或頁碼、核實日期及狀態。

## 開發階段
1. 建立全校學院與系所清單
2. 逐系整理各入學年度畢業規定
3. 完成 AND／OR／至少 N 項／學分門檻／先修規則
4. 建立課程目錄與成績資料匯入
5. 整理輔系、雙主修、學分學程資格、申請、審查、核准及修課規則
6. 比較修讀路徑與正式允許的學分重複計算方式

本工具僅供學業規劃參考，不取代中興大學教務處、各系所或學程的正式規定與審查結果。
